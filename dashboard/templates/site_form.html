Window 1: checks every 1 min from 06:55–07:10 Mon–Fri (catches the early morning RNS drop).
Window 2: checks every 5 min from 07:10–17:00 Mon–Fri (full market hours coverage).

JavaScript Rendering ▸
When do you need this?
Some websites build their content in the browser — the page loads empty first, then fills in with data. A normal fetch only gets the empty shell.

How to tell if you need it: After adding a site, check its Inspect page. If it shows 0 or very few words (<50), enable this.

Trade-off: Adds 5–15 seconds per check. Use only when needed.
